### Анализ

В ходе расследования событий на хосте `10.156.18.200` обнаружена последовательность подозрительной активности, указывающая на успешную фишинговую атаку

Первоначально был выявлен запуск `WINWORD.EXE`, в командной строке которого присутствовал документ `Doc1.doc`. По данным песочницы документ классифицирован как вредоносный. Его SHA-1 `a9d722ba97b411468b4b899f2fa582a92ba3fcc1`. В качестве пользователя, открывшего документ, определена учётная запись `t_santos`. PID процесса `WINWORD.EXE` - `1852`

При дальнейшем анализе дерева процессов обнаружен запуск `powershell.exe` с PID `624`, родительским процессом которого являлся `WINWORD.EXE` (PID `1852`). PowerShell был запущен с параметрами `-nop -w hidden -e`, что указывает на выполнение Base64-кодированной команды в скрытом окне без загрузки профиля.

После декодирования команды обнаружена реализация Reverse Shell с использованием `System.Net.Sockets.TCPClient`. Скрипт устанавливал TCP-подключение к `7.tcp.eu.ngrok.io:17344`, получал команды от удалённой стороны, выполнял их через `Invoke-Expression` (`iex`) и отправлял результаты обратно. Это свидетельствует о наличии механизма удалённого выполнения команд на целевом хосте

Среди дочерних процессов PowerShell обнаружен запуск `met.exe` из каталога `C:\Users\t_santos\Documents\`. Также выявлены команды разведки `whoami.exe` и `ipconfig.exe`

При дополнительном анализе событий PowerShell 4104 обнаружена команда загрузки файла `met2.exe` с внешнего ресурса `http://rser.inostage.ru/XNzAOnof/met2.exe` с сохранением под именем `met.exe`. Создание файла `C:\Users\t_santos\Documents\met.exe` процессом PowerShell с PID `624` подтверждается событием Sysmon Event ID 11

Запущенный `met.exe` получил PID `2696`. В ходе дальнейшего анализа обнаружено его подключение к именованному каналу `wkssvc`, а также сетевое соединение с адресом `10.126.10.30:10000` 

Особое внимание привлекло событие Sysmon Event ID 10, в котором `met.exe` обращается к процессу `lsass.exe` с PID `784`. Значение `GrantedAccess = 0x1010` включает права на чтение памяти процесса (`PROCESS_VM_READ`) и ограниченный запрос информации (`PROCESS_QUERY_LIMITED_INFORMATION`)

Дополнительно обнаружено создание процессом `met.exe` файла `nkcklq.dll` в каталоге `C:\Users\t_santos\AppData\Local\Temp\`. Впоследствии SIEM сформировала корреляционный инцидент `LSASS_Memory_Dump`, объединивший события доступа к LSASS и создания подозрительного файла

Таким образом, обнаруженные события указывают на подозрительную активность, направленную на получение доступа к данным процесса LSASS. При этом события подтверждают доступ к процессу и создание файла, но сами по себе не доказывают успешное извлечение дампа памяти или фактическую кражу учётных данных

### Заключение

На хосте `10.156.18.200` обнаружена цепочка активности, начавшаяся с открытия вредоносного документа `Doc1.doc` пользователем `t_santos`

Документ инициировал запуск PowerShell, содержащего Reverse Shell. После чего PowerShell загрузил и запустил `met.exe`, который установил сетевое соединение с внешним узлом, обратился к процессу LSASS и создал подозрительный файл `nkcklq.dll`

Совокупность событий и срабатывание корреляционного правила `LSASS_Memory_Dump` указывают на попытку компрометации данных. Успешное извлечение учётных данных по имеющимся данным не подтверждено
