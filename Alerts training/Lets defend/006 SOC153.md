# SOC153 — Suspicious PowerShell Script Executed

![[Pasted image 20261101053916.png]]

Вердикт: True Positive  

Критичность: Medium  

Affected host: Tony (`172.16.17.206`)  

IoC: `https://files-ld.s3.us-east-2.amazonaws.com/payload_1.ps1`, `payload_1.ps1`, `db8be06ba6d2d3595dd0c86654a48cfc4c0c5408fdd3f4e1eaf342ac7a2479d0`, `C:\Users\LetsDefend\Downloads\payload_1.ps1` 

Анализ:  При анализе истории браузера обнаружено обращение к `https://files-ld.s3.us-east-2.amazonaws.com/payload_1.ps1`. Ссылка ведёт к файлу с тем же именем, который указан в алерте. URL отмечен как вредоносный. При изучении процессов на целевом хосте не обнаружено подозрительных процессов, связанных с запуском скрипта. История терминала пуста. Содержимое файла и его фактическое поведение не удалось исследовать. Данных, достаточных для подтверждения дальнейшей загрузки пейлоада, C2-коммуникации или бокового перемещения, не получено

Заключение: обнаружение связано с подозрительным PowerShell-файлом, загруженным по URL, отмеченному как вредоносный. Факт успешного выполнения пейлоада и компрометации хоста на основании доступной телеметрии не подтверждён.

Рекомендации: Изолировать хост, проверить наличие и состояние `payload_1.ps1`, поместить файл в карантин и удалить после изучение, заблокировать вредоносный URL и проверить наличие обращений на других хостах, проверить учётную запись пользователя на предмет подозрительной активности, сохранить в IoC индикаторы атаки
