
# 2026-10-29T00:36:07.820311+03:00 SOC342 - CVE‑2025‑53770 SharePoint ToolShell Auth Bypass and RCE

Вердикт: True positive

Критичность: Critical

Affected hosts: 172.16.20.17

Source IP:  107.191.58.76

Анализ: При анализе алерта был замечен подозрительный post запрос к /_layouts/15/ToolPane.aspx, который может быть связан с эксплуатацией SharePoint ToolShell (CVE-2025-53770). При изучении процессов в EDR на затронутом хосте была замечена цепочка процессов указывающих на эксплуатацию уязвимости. w3wp.exe запустил скрытый PowerShell. Затем csc.exe попытался скомпилировать исполняемый файл payload.exe, а cmd.exe — создать файл spinstall0.aspx в каталоге SharePoint. Также обнаруженный код пытается получить криптографические ключи ASP.NET. Хост изолирован на момент анализа

Заключение: Совокупность всех зацепок указывают на попытку эксплуатации уязвимости и вероятную компрометацию хоста, однако имеющиеся данные не не подтверждают запуск пейлоада или реальную эксфильтрацию данных.

Рекомендации: Изолировать сервер, сохранить журналы событий и другие доступные данные для дальнейшего анализа, проверить наличие и содержимое подозрительных файлов, выяснить, запускался ли `payload.exe` и использовался ли файл `spinstall0.aspx`. Также необходимо оценить возможную утечку криптографических ключей и проверить сервер на другие признаки компрометации
