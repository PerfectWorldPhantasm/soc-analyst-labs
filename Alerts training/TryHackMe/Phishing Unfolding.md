**Анализ:**

В ходе расследования были обнаружены два связанных оповещения.

Первое оповещение (ID 1007, Low) указывало на подозрительное вложение во входящем письме от `john@hatmakereurope.xyz`, адресованном пользователю `michael.ascot`

Проверка репутации домена отправителя не выявила угроз. Однако дальнейший поиск в Splunk обнаружил события, связанные с вложением. Sysmon Event ID 15 указал на создание альтернативного потока данных. При анализе файла была обнаружена маскировка под PDF: файл с расширением `.pdf.lnk` фактически являлся ярлыком Windows (LNK). Анализ в TryDetectThis подтвердил его вредоносность

Второе оповещение (ID 1027, High) указывало на подозрительное создание процесса на хосте `win-3450`.

Поиск событий в Splunk:

```
index=* host=win-3450
```

Была обнаружена следующая связь процессов:

```
powershell.exe
    └── nslookup.exe
```

Процесс `nslookup.exe` был запущен PowerShell с аргументом, содержащим подозрительную строку и домен `haz4rdw4re.io`. Рабочая директория процесса:

```
C:\Users\michael.ascot\Downloads\exfiltration\
```

Дополнительный анализ PowerShell-сценария показал, что он считывал содержимое архива `exfilt8me.zip` и передавал данные посредством серии DNS-запросов к внешней инфраструктуре, включая `haz4rdw4re.io`

Таким образом, использование PowerShell совместно с `nslookup.exe` было частью механизма DNS-эксфильтрации данных

**Заключение:**

Расследование выявило фишинговое письмо с вредоносным вложением, замаскированным под PDF, и последующую активность, связанную с DNS-эксфильтрацией данных

Злоумышленник использовал PowerShell для обработки архива и `nslookup.exe` для передачи его содержимого через DNS-запросы. Обнаруженная активность указывает на компрометацию пользовательской рабочей станции и потенциальную утечку данных.

Точная последовательность выполнения вредоносного LNK-файла и его связь с обнаруженным PowerShell-сценарием имеющимися артефактами не подтверждена
